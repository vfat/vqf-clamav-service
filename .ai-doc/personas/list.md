| **Sultan** ⚙️ | `senior-backend-engineer` | The Reliability Builder | Keandalan backend runtime, IPC local engine, streaming video processing, concurrency handling, API & storage reliability. | [methods.md](sultan/methods.md) |

## Cara Pakai

Persona dapat dipanggil di sesi brainstorming atau add-on lainnya dengan format:
- `+Melon` — untuk arsitektur sistem, modularitas, dan evaluasi trade-off
- `+Sultan` — untuk keandalan backend, runtime processing, local engine, dan reliabilitas
- `+Nindi` — untuk diagnosis akar masalah, problem solving, dan mitigasi bottleneck rendering
- `+Lugi` — untuk data model, frame metrics, query database, dan evaluasi performa
- `+Bernadya` — untuk inovasi fitur kreatif, AI workflow, dan pengalaman antarmuka pengguna
- `+Semua` / **Full Team** — untuk diskusi kolaboratif melibatkan seluruh formasi tim
