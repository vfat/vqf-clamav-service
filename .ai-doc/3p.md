## 3. Pending (Issues & PR to Discuss)
Daftar pertanyaan terbuka, debt teknis, dan isu keamanan krusial yang perlu dibahas:

- [ ] **⚠️ Issue #1: XOR Scrambling BUKAN Encryption (CRITICAL SECURITY REVIEW)**
  - **Konteks:**  
    Implementasi `internal/quarantine/vault.go` saat ini masih menggunakan fungsi masking statis:
    ```go
    func scrambleBytes(data []byte) []byte {
        for i, b := range data { out[i] = b ^ 0xA5 }
    }
    ```
  - **Poin Bahasan & Resiko Keamanan:**
    1. **Trivial Reversal:** XOR dengan static mask `0xA5` adalah metode obfusikasi sepele yang dapat di-*reverse* dalam 1 baris kode (`b ^ 0xA5`).
    2. **Instant Weaponization:** Attacker yang berhasil memperoleh akses *read* ke volume `/data/quarantine/` dapat men-*descramble* kembali sampel malware berbahaya dalam hitungan detik.
    3. **Blueprint Non-Compliance:** Desain awal arsitektur dan standar keamanan enterprise mensyaratkan enkripsi authenticated **AES-256-GCM**.
    4. **False Neutralization:** Jika file malware terisolasi bocor atau terekspos dari container, payload tersebut hakikatnya **belum ternetralisir secara kriptografis**.
  - **Action Plan / Rencana Perbaikan:**
    - Hubungkan `internal/quarantine/vault.go` dengan helper `crypto.EncryptAESGCM` dan `crypto.DecryptAESGCM` yang sudah tersedia di `internal/crypto`.
    - Gunakan `MASTER_KEY` dari environment variables (dengan auto-generated fallback 32-byte key yang aman) untuk mengenkripsi setiap payload yang disimpan di disk vault.
    - Sediakan migrasi atau backward compatibility untuk payload lama yang masih berformat XOR.
